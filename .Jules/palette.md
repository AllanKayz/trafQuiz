## 2026-02-08 - [Messaging Micro-UX Improvements]
**Learning:** Adding ARIA labels and tooltips to icon-only buttons is a fundamental accessibility requirement that also improves discoverability for new users. Visual feedback like character counts and clear-search buttons significantly reduce friction in high-frequency interaction areas like messaging.
**Action:** Always check search inputs for a clear-search capability and ensure all interactive elements have appropriate ARIA labels and tooltips. Enforce message limits with visual cues to prevent silent truncation or backend errors.
